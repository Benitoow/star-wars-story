# Legacy JavaScript prototype

This folder documents the archived vanilla JavaScript version of **Star Wars Story**.

The original classic frontend lived in the repository root and was built around:

- `index.html`
- `css/style.css`
- `js/api.js`
- `js/app.js`
- `js/config.js`
- `js/story.js`

That version is no longer the public play target. The playable deployment is now the Cloudflare-hosted site, and the repository keeps this legacy material only for reference and historical context.

If you need the old prototype behavior, inspect the repository history or the archived source tree rather than treating the root static files as the active entrypoint.
